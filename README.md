# AeroPost 3D — Настольная почтовая программа для Windows 10/11

**AeroPost 3D** — настольное Windows-приложение для сбора корреспонденции с разных почтовых серверов (Gmail API, Google Chat, Яндекс.Почта IMAP SSL, корпоративный Exchange / JMAP) с 3D-визуализацией прилетающего на рабочий стол конверта (Three.js), настраиваемыми Push-уведомлениями, системой правил фильтрации и сортировки, голосовым чтением писем (`gemini-3.8-flash-tts`) и ИИ-Аналитиком дедлайнов (`gemini-3.8-flash` / `gemini-4-argon` / `gemini-3.1-flash-lite`).

---

## Ключевые возможности Windows-приложения

1. **Режим рабочего стола Windows («Только 3D-конверт»)**:
   - В свернутом состоянии на рабочем столе отображается только 3D-конверт с сургучной печатью.
   - При поступлении нового письма конверт прилетает на рабочий стол, воспроизводится звуковой сигнал и появляется уведомление Windows с именем отправителя и темой.
   - При клике по 3D-конверту верхний клапан плавно открывается, письмо выдвигается вверх и автоматически разворачивается главное окно почтовой программы со списком новых писем.
2. **ИИ-Аналитик дедлайнов во вкладке «ИИ-Почтальон»**:
   - Автоматически анализирует текст выбранного письма и выводит в карточку письма сводку ключевых дедлайнов (**Дата · Время · Суть события**) в виде выделенных интерактивных тегов.
   - Многошаговый диалог с ИИ-Почтальоном с поддержкой выбора ролей и моделей (`gemini-3.8-flash`, `gemini-3.1-flash-lite`, `gemini-4-argon`).
3. **Фильтрация, сортировка и правила автоматической обработки**:
   - Создание правил на основе отправителя, домена, темы, содержания и сервера получения.
   - Автоматическая расстановка папок/категорий, приоритетов, меток `★ Избранное`, управление режимом Push-уведомлений и авто-озвучиванием.
4. **Голосовое озвучивание писем (`gemini-3.8-flash-tts`)**:
   - Одно- и двухголосый синтез речи (Диктор + Автор письма) в формате WAV 24 кГц.

## Сборка нативного Windows-приложения (`.exe`) и отправка в GitHub

### 1. Локальная сборка `.exe` на Windows 10 / 11

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/<ваш-аккаунт>/aeropost-3d-windows.git
cd aeropost-3d-windows

# 2. Создайте файл .env и укажите ваш ключ Gemini API
cp .env.example .env

# 3. Установите зависимости и пакеты сборки Electron
npm install
npm install --save-dev electron electron-builder

# 4. Запустите приложение в режиме настольного окна Windows
npm run electron:dev

# 5. Соберите установочный (NSIS Setup.exe) и портативный (Portable.exe) файлы для Windows x64
npm run dist:win
```

После завершения команды `npm run dist:win` готовые исполняемые файлы для Windows появятся в папке `release/`:
- `release/AeroPost 3D Mail-1.0.0-x64.exe` (Установщик Windows с ярлыком на рабочем столе и в меню «Пуск»)
- `release/AeroPost 3D Mail-1.0.0-x64-portable.exe` (Портативная версия без установки)

### 2. Автоматическая сборка `.exe` через GitHub Actions

В репозитории уже настроен файл `.github/workflows/build-windows-exe.yml`. При каждом `git push` в ветку `main` или `master` GitHub Actions автоматически поднимает виртуальную машину `windows-latest`, компилирует проект и прикрепляет готовый архив `AeroPost-3D-Windows-EXE` (`.exe`) во вкладке **Actions → Artifacts**.
